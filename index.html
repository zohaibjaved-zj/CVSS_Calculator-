About CVSS 3.1

The Common Vulnerability Scoring System (CVSS) is an open framework for rating the severity of software vulnerabilities on a 0–10 scale. Version 3.1 is maintained by FIRST.org.

  • Base metrics capture the intrinsic qualities of a vulnerability that stay constant over time and across environments.
  • Temporal metrics layer on factors that change over time, such as exploit maturity and patch availability.
  • Environmental metrics let an organization adjust the score to its own deployment, weighting confidentiality, integrity, and availability requirements.

Every score is backed by a vector string — a compact, shareable encoding of the metric choices behind it — which this tool generates, parses, and lets you copy or load directly.
